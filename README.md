Aim

To write a Python program to validate an email ID or a 10-digit mobile number
using Regular Expressions.

Algorithm

1.Start the program.

2.Import the re module.

3.Get email or mobile number as input from the user.

4.Define regular expressions for email and mobile number.

5.Use re.fullmatch() to check the input.

6.If email matches, print "valid email".

7.If mobile number matches, print "valid phone number".
Otherwise, print "invalid input".

8.Stop the program.
